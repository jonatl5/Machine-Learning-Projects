# Lab 7 Reflection

## 1. What differences did you observe?

The baseline model could recognize many digits, but some predictions were less confident or less consistent because it was trained on the provided dataset. After fine-tuning, the model was better matched to my own gesture style, angle, and motion patterns.

## 2. Which model performed better and why?

The fine-tuned model performed better because it learned from my collected gesture data. Those examples were closer to the way I personally moved the Arduino, so the model became more reliable for my digits.

## 3. Did fine-tuning help for your specific gesture style?

Yes, fine-tuning helped because my gestures were not exactly the same as the original training data. Using my own data made the model more personalized and improved its ability to recognize my specific drawing style.
